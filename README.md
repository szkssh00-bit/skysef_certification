# SKYSEF Certification System

This repository provides a GitHub Pages front end and Google Apps Script backend for the SKYSEF 2026 participant questionnaire and private Certificate of Participation PDF generation.

## Main features

This v4 build fixes the mobile vertical layout, server-side date limits, certificate-period reflection, and spreadsheet column mapping.


- Questionnaire is shown first.
- After the server accepts the response, the page transitions to the certificate screen.
- Individual PDF is generated by Google Apps Script, not by browser printing.
- PDF is saved to the configured private Google Drive folder.
- All questionnaire responses are recorded in the configured Google Spreadsheet.
- Certificate text changes according to the selected participation period.
- Mobile layout is optimized for large touch targets and readable form cards.
